# Security rules

- Never commit or emit private keys, mnemonics, access tokens, RPC secrets, or
  production credentials.
- Contract purchase, course publication, and certificate mint facts must be
  checked against the configured chain and contract addresses.
- Privileged contract/admin operations, Sepolia deployment, cloud resources,
  permissions, security scans, and paid actions require separate confirmation.
- Certificate metadata must remain content-addressed and contain no PII.
