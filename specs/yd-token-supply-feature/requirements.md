# YD 固定供应量调整需求

## 目标

- 将 `YDToken` 固定总供应量从 1,000,000 YD 调整为 80,000,000 YD。
- 部署时一次性将全部供应量铸给非零 Treasury 地址。
- 保持无后续增发能力的固定供应模型。

## 非目标

- 不增加 `mint`、角色权限、代理升级或治理功能。
- 不修改代币名称 `YiDeng Token`、符号 `YD` 或 18 位小数。
- 不修改课程价格、75%/25% 分账或 Uniswap 初始兑换比例。
- 不部署 Sepolia，不读取或写入私钥、RPC 密钥和真实地址。

## 功能需求

- FR-001：`INITIAL_SUPPLY` 必须精确为 `80_000_000 ether`。
- FR-002：构造时必须将全部供应量一次性铸给 Treasury。
- FR-003：零地址 Treasury 继续失败，合约不得暴露后续增发入口。
- FR-004：合约测试和架构文档中的固定供应量必须保持一致。

## 验收标准

- AC-001：部署后的 `totalSupply()` 和 Treasury 余额均为 `80_000_000 ether`。
- AC-002：合约仍只有构造函数铸币路径，没有公开或受权 `mint` 方法。
- AC-003：零地址 Treasury 负例和课程市场既有行为测试通过。
- AC-004：合约 README 与架构文档均声明固定发行 80,000,000 YD。
- AC-005：Foundry 聚焦测试和格式检查通过，且没有执行链上部署。

## 边界与依赖

- 当前仓库没有 Sepolia 部署回执，因此本次只改变未来部署制品。
- 未来若需要超过 80,000,000 YD，只能重新设计并部署新版本；本任务不预建增发能力。
